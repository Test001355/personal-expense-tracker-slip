# SlipTrack — Personal Expense Tracker Web App with Slip-Based Input

ระบบเว็บแอปพลิเคชันสำหรับบันทึกและติดตามรายรับ–รายจ่ายส่วนบุคคล พร้อมฟีเจอร์อัปโหลดรูปภาพสลิปโอนเงิน/ใบเสร็จเพื่อช่วยบันทึกค่าใช้จ่าย แนะนำหมวดหมู่แบบอัตโนมัติจากคำสำคัญ (Rule-Based Keyword Matching) และแสดงผล Dashboard สรุปยอดพร้อมกราฟแยกตามหมวดหมู่

---

## 1. ฟีเจอร์หลักของระบบ (Key Features)

### ขอบเขตหลัก (Core MVP Features)
- **FR-01 เพิ่มรายการรายรับ–รายจ่ายด้วยตนเอง:** บันทึกประเภทธุรกรรม (รายรับ/รายจ่าย), จำนวนเงิน, วันที่, ชื่อร้านค้า/ผู้รับเงิน, หมวดหมู่, วิธีชำระเงิน และรายละเอียดเพิ่มเติม
- **FR-02 อัปโหลดสลิปค่าใช้จ่าย:** รองรับการอัปโหลดรูปภาพสลิป (Drag & Drop หรือเลือกไฟล์จากเครื่อง) พร้อมบีบอัดรูปอัตโนมัติและแสดงตัวอย่างรูปสลิปทันที (มีปุ่มจำลองสลิปตัวอย่างให้ทดสอบได้ในคลิกเดียว)
- **FR-03 บันทึกข้อมูลจากสลิป:** แสดงรูปสลิปคู่กับฟอร์มกรอกข้อมูล เพื่อให้ผู้ใช้ดูข้อมูลจากสลิปแล้วกรอกจำนวนเงิน วันที่ ร้านค้า และรายละเอียดได้อย่างสะดวก
- **FR-04 & FR-05 แก้ไขและลบรายการ:** ดูรายละเอียดรายการพร้อมรูปสลิปที่แนบไว้ แก้ไขข้อมูลทุกฟิลด์ หรือลบรายการที่ไม่ต้องการได้
- **FR-06 แสดงรายการทั้งหมด:** รองรับการแสดงผลทั้งรูปแบบ **ตาราง (Table View)** และ **การ์ด (Card Grid View)**
- **FR-07 ค้นหาและกรองข้อมูล:** ค้นหาจากคำสำคัญ (ชื่อร้านค้า/รายละเอียด) และกรองตามประเภท (รายรับ/รายจ่าย), หมวดหมู่, หรือช่วงวันที่ (ตั้งแต่วันที่ - ถึงวันที่)
- **FR-08 ระบบแนะนำหมวดหมู่แบบง่าย (Rule-Based Category Suggestion):** วิเคราะห์คำสำคัญจากชื่อร้านค้าหรือรายละเอียดแล้วเลือกหมวดหมู่ให้อัตโนมัติ เช่น:
  - `7-Eleven, Lotus, Big C, Cafe, Food` $\rightarrow$ **อาหารและเครื่องดื่ม**
  - `Grab, Bolt, Bus, Taxi, Fuel, Gas` $\rightarrow$ **เดินทาง**
  - `Book, Course, Tuition, Stationery` $\rightarrow$ **การเรียน**
  - `Shopee, Lazada, Shopping, Mall` $\rightarrow$ **ช้อปปิ้ง**
  - `Electric, Water, Internet, Phone` $\rightarrow$ **บิลและค่าสาธารณูปโภค**
  - `Hospital, Clinic, Medicine` $\rightarrow$ **สุขภาพ**
  - `Movie, Game, Music` $\rightarrow$ **ความบันเทิง**
- **FR-09 Dashboard สรุปภาพรวม:** แสดงยอดรวมรายรับ (Total Income), ยอดรวมรายจ่าย (Total Expense) และยอดคงเหลือสุทธิ (Net Balance)
- **FR-10 กราฟสรุปค่าใช้จ่ายตามหมวดหมู่:** แสดงกราฟวงกลม (Doughnut/Pie Chart) และกราฟแท่ง (Bar Chart) ด้วย Chart.js
- **FR-11 จัดเก็บข้อมูลและรูปภาพสลิป:** จัดเก็บข้อมูลผ่าน `LocalStorage` พร้อมข้อมูลตัวอย่าง (Sample Data) สำหรับทดสอบได้ทันที

### ฟีเจอร์เสริมที่พัฒนาเพิ่มเติม (Optional Advanced Features)
- **Export รายงานเป็นไฟล์ CSV:** ดาวน์โหลดรายการธุรกรรมทั้งหมดเป็นไฟล์ `.csv` รองรับภาษาไทย (UTF-8 BOM) เปิดใน Excel ได้ทันที
- **ตั้งงบประมาณรายเดือนและแจ้งเตือนเมื่อใช้เกินงบ:** แสดงแถบความคืบหน้างบประมาณรายเดือน พร้อมแจ้งเตือนเมื่อใช้จ่ายเกิน 80% หรือเกินงบที่ตั้งไว้
- **Dark Mode / Light Mode:** สลับโหมดหน้าจอมืด–สว่างได้ตามความต้องการ
- **จัดการหมวดหมู่ (Category Management):** สามารถเพิ่มหมวดหมู่รายรับ–รายจ่ายใหม่เพิ่มเติมจากหมวดหมู่เริ่มต้น 9 หมวดหมู่ได้

## 3. วิธีติดตั้งและรันโปรเจกต์ (Installation & Usage)

### วิธีที่ 1: เปิดใช้งานได้ทันทีผ่านเว็บเบราว์เซอร์
1. ดาวน์โหลดหรือ Clone โปรเจกต์จาก GitHub Repository:
   ```bash
   git clone <GITHUB_REPO_URL>
   cd "Personal Expense Tracker Web App"
   ```
2. เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ (Google Chrome, Microsoft Edge, Firefox, Safari) ได้ทันที

### วิธีที่ 2: รันผ่าน Local Web Server (แนะนำ)
- หากมี Node.js ติดตั้งอยู่ในเครื่อง สามารถรันคำสั่ง:
  ```bash
  npx serve .
  ```
- หรือใช้ส่วนเสริม **Live Server** บน VS Code แล้วเปิดผ่าน `http://localhost:3000` หรือ `http://127.0.0.1:5500`

## 4. วิธีใช้งานระบบ (User Guide)

1. **ดูสรุปภาพรวม (Dashboard):** เมื่อเข้าสู่เว็บไซต์ ระบบจะโหลดข้อมูลตัวอย่าง (Sample Data) พร้อมแสดงการ์ดสรุปยอดรวมรายรับ รายจ่าย ยอดคงเหลือ และกราฟสรุปค่าใช้จ่ายตามหมวดหมู่
2. **อัปโหลดสลิปค่าใช้จ่าย:**
   - คลิกเมนู **"อัปโหลดสลิปค่าใช้จ่าย"**
   - เลือกรูปภาพสลิปจากอุปกรณ์ หรือกดปุ่ม **"🧾 สลิป 7-Eleven" / "🚕 สลิป GrabTransport" / "🛍️ สลิป Shopee"** เพื่อทดสอบด้วยสลิปตัวอย่างทันที
   - กรอกชื่อร้านค้าและจำนวนเงิน ระบบจะแนะนำและเลือกหมวดหมู่ให้อัตโนมัติตามคำสำคัญ จากนั้นกด **"บันทึกข้อมูลพร้อมรูปภาพสลิป"**
3. **เพิ่มรายการแบบกรอกเอง:** คลิกเมนู **"เพิ่มรายการ (กรอกเอง)"** เลือกประเภทรายจ่ายหรือรายรับ กรอกจำนวนเงิน วันที่ และชื่อร้านค้า แล้วกดบันทึก
4. **ค้นหา กรอง แก้ไข และลบรายการ:** คลิกเมนู **"รายการธุรกรรมทั้งหมด"** สามารถพิมพ์คำค้นหา เลือกหมวดหมู่ หรือช่วงวันที่ กดปุ่ม **"ดูสลิป / แก้ไข"** เพื่อดูรูปสลิปขนาดใหญ่หรือแก้ไขข้อมูล และกดปุ่มถังขยะเพื่อลบรายการ

## 5. สรุปการใช้เครื่องมือ AI ในการพัฒนา (AI Tools Usage Summary)

โปรเจกต์นี้พัฒนาโดยใช้ **Antigravity (AI Coding Assistant)** ช่วยในขั้นตอนต่าง ๆ ดังนี้:
1. **ออกแบบโครงสร้างโปรเจกต์และ Data Model:** แยกโมดูลออกเป็น `data.js`, `chart-manager.js`, และ `app.js` ตามหลักการแยกส่วนรับผิดชอบ (Separation of Concerns - NFR-07)
2. **พัฒนาฟังก์ชัน CRUD และการจัดเก็บข้อมูล:** สร้าง `DataService` สำหรับจัดการข้อมูล `Transaction` และ `Category` ใน `LocalStorage` พร้อมระบบบีบอัดรูปภาพสลิปด้วย HTML5 Canvas
3. **สร้างระบบแนะนำหมวดหมู่แบบ Rule-Based (`suggestCategoryByKeyword`):** จับคู่คำสำคัญทั้งภาษาอังกฤษและภาษาไทยเข้ากับหมวดหมู่เริ่มต้นทั้ง 9 หมวดหมู่
4. **ออกแบบและปรับแต่ง Responsive UI:** จัดทำหน้าจอ Dashboard, ตารางรายการธุรกรรม, หน้าอัปโหลดสลิปแบบ 2 คอลัมน์ (แสดงรูปสลิปคู่กับฟอร์มกรอกข้อมูล) และรองรับหน้าจอมือถือ/แท็บเล็ต
5. **สร้างข้อมูลตัวอย่าง (Sample Data) และจัดทำเอกสาร:** สร้างสลิปจำลองรูปแบบ SVG และจัดทำเอกสาร `README.md` และรายงานฉบับสมบูรณ์ `REPORT.md`
