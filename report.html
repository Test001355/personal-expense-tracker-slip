โครงการ: Personal Expense Tracker Web App with Slip-Based Input
ระบบบันทึกรายรับ–รายจ่ายส่วนบุคคล พร้อมอัปโหลดสลิปเพื่อช่วยบันทึกข้อมูลค่าใช้จ่าย
ลิงก์ผลงานที่ส่ง (Project Deliverables):
• GitHub Repository URL: https://github.com/Test001355/personal-expense-tracker-slip
• Demo URL (ใช้งานจริงผ่านเว็บ): https://test001355.github.io/personal-expense-tracker-slip/

1. ภาพรวมและแนวคิดของระบบ (System Overview)

ระบบ Personal Expense Tracker Web App with Slip-Based Input (SlipTrack) เป็นเว็บแอปพลิเคชันสำหรับบันทึกและติดตามรายรับ–รายจ่ายส่วนบุคคล โดยออกแบบให้ผู้ใช้งานสามารถเพิ่มรายการรายรับ–รายจ่ายได้ 2 วิธีหลัก ได้แก่:

  1. กรอกข้อมูลด้วยตนเอง (Manual Input): ผู้ใช้กรอกประเภท (รายรับ/รายจ่าย) จำนวนเงิน วันที่ ชื่อร้านค้า หมวดหมู่ และรายละเอียดด้วยตนเอง
  2. อัปโหลดรูปภาพสลิปโอนเงินหรือสลิปจ่ายเงิน (Slip-Based Input): ผู้ใช้อัปโหลดรูปสลิปเข้าสู่ระบบ ระบบจะแสดงภาพตัวอย่างสลิปควบคู่กับฟอร์มกรอกข้อมูล พร้อมระบบแนะนำหมวดหมู่ค่าใช้จ่ายแบบง่ายจากคำสำคัญ (Rule-Based Keyword Suggestion) เช่น เมื่อพิมพ์คำว่า "7-Eleven" ระบบจะแนะนำและเลือกหมวดหมู่ "อาหารและเครื่องดื่ม" ให้อัตโนมัติ

2. วัตถุประสงค์ของระบบ (Objectives)

  1. เพื่อพัฒนาเว็บแอปพลิเคชันสำหรับบันทึกรายรับ–รายจ่ายส่วนบุคคล
  2. เพื่อให้ผู้ใช้สามารถบันทึกรายการค่าใช้จ่ายควบคู่กับหลักฐานรูปภาพสลิปได้
  3. เพื่อฝึกการพัฒนาระบบ CRUD (เพิ่ม/อ่าน/แก้ไข/ลบ), File Upload, Search, Filter และ Dashboard
  4. เพื่อฝึกการออกแบบโครงสร้างฐานข้อมูลและการจัดเก็บรูปภาพประกอบรายการธุรกรรม
  5. เพื่อประยุกต์ใช้ AI Tools ช่วยในการออกแบบ พัฒนา แก้ไขโค้ด และจัดทำเอกสารประกอบโปรเจกต์

3. กลุ่มผู้ใช้งาน (Target Users)

  1. นักศึกษา: ที่ต้องการบริหารจัดการรายรับ–รายจ่ายรายเดือน
  2. บุคคลทั่วไป: ที่ต้องการติดตามค่าใช้จ่ายส่วนตัวในชีวิตประจำวัน
  3. ผู้ใช้ที่ต้องการเก็บหลักฐานสลิป: ผู้ที่ต้องการเก็บรูปภาพสลิปโอนเงินหรือใบเสร็จควบคู่กับรายการรายจ่ายเพื่อตรวจสอบย้อนหลัง

4. ขอบเขตของระบบและฟีเจอร์ที่พัฒนา (System Scope & Features)

4.1 ขอบเขตหลัก (Core MVP Scope)

  1. เพิ่มรายการรายรับ–รายจ่ายด้วยตนเอง
  2. อัปโหลดรูปภาพสลิปประกอบรายการรายจ่าย พร้อมแสดงตัวอย่างรูปสลิป
  3. แก้ไขข้อมูลรายการรายรับ–รายจ่าย
  4. ลบรายการรายรับ–รายจ่าย
  5. แสดงรายการรายรับ–รายจ่ายทั้งหมด (สลับมุมมองตาราง Table และการ์ด Card ได้)
  6. ค้นหาจากคำสำคัญ และกรองรายการตามประเภท หมวดหมู่ หรือช่วงวันที่
  7. แสดง Dashboard สรุปรายรับ รายจ่าย และยอดคงเหลือสุทธิ
  8. แสดงกราฟสรุปรายจ่ายตามหมวดหมู่ (Pie/Doughnut Chart และ Bar Chart)
  9. แนะนำหมวดหมู่ค่าใช้จ่ายแบบง่ายจากคำสำคัญ (Rule-Based)
  10. Deploy ระบบให้สามารถใช้งานผ่าน URL สาธารณะได้จริง (GitHub Pages)

4.2 ฟีเจอร์เสริมที่ได้พัฒนาเพิ่มเติม (Optional Advanced Features)

  1. Export รายงานเป็นไฟล์ CSV: ดาวน์โหลดข้อมูลธุรกรรมทั้งหมดไปเปิดในโปรแกรม Microsoft Excel ได้ทันที
  2. ตั้งงบประมาณรายเดือนและแจ้งเตือนเมื่อใช้เกินงบ: กำหนดงบรายจ่ายต่อเดือน พร้อมแถบสถานะและข้อความแจ้งเตือนเมื่อใช้จ่ายเกินงบ
  3. โหมดมืด/สว่าง (Dark Mode / Light Mode): ปรับเปลี่ยนธีมสีของหน้าเว็บได้ตามต้องการ
  4. การจัดการหมวดหมู่เพิ่มเติม: สามารถเพิ่มหมวดหมู่ใหม่นอกเหนือจากหมวดหมู่เริ่มต้น 9 หมวดหมู่ได้

5. ความต้องการเชิงฟังก์ชัน (Functional Requirements)

รหัส รายการความต้องการ รายละเอียดการทำงาน สถานะ
FR-01เพิ่มรายการรายรับ–รายจ่ายผู้ใช้กรอกวันที่ ประเภท จำนวนเงิน ร้านค้า หมวดหมู่ วิธีชำระเงิน และรายละเอียดได้สำเร็จ
FR-02อัปโหลดสลิปผู้ใช้อัปโหลดรูปภาพสลิปประกอบรายการรายจ่าย พร้อมแสดงภาพตัวอย่างสลิปสำเร็จ
FR-03บันทึกข้อมูลจากสลิปหลังอัปโหลดสลิป ผู้ใช้กรอกจำนวนเงิน วันที่ ร้านค้า/ผู้รับเงิน และรายละเอียดเพิ่มเติมได้สำเร็จ
FR-04แก้ไขรายการผู้ใช้แก้ไขข้อมูลรายการและรูปสลิปที่บันทึกไว้ได้ผ่านหน้าต่าง Modalสำเร็จ
FR-05ลบรายการผู้ใช้ลบรายการที่ไม่ต้องการได้ พร้อมระบบยืนยันก่อนลบสำเร็จ
FR-06แสดงรายการทั้งหมดแสดงรายการรายรับ–รายจ่ายทั้งหมดในรูปแบบตาราง (Table) หรือการ์ด (Card)สำเร็จ
FR-07ค้นหาและกรองข้อมูลค้นหาจากคำสำคัญ และกรองตามประเภท หมวดหมู่ หรือช่วงวันที่ได้สำเร็จ
FR-08แนะนำหมวดหมู่แนะนำหมวดหมู่อัตโนมัติจากคำสำคัญ เช่น 7-Eleven, Grab, Shopeeสำเร็จ
FR-09Dashboardแสดงยอดรวมรายรับ รายจ่าย และยอดคงเหลือสุทธิอย่างถูกต้องสำเร็จ
FR-10กราฟสรุปค่าใช้จ่ายแสดงกราฟรายจ่ายตามหมวดหมู่ทั้งแบบ Pie Chart และ Bar Chart ด้วย Chart.jsสำเร็จ
FR-11จัดเก็บข้อมูลจัดเก็บข้อมูลธุรกรรม หมวดหมู่ และรูปภาพสลิปใน LocalStorageสำเร็จ
FR-12Deploy ระบบเปิดใช้งานผ่าน URL สาธารณะบน GitHub Pages ได้จริงสำเร็จ

6. การออกแบบฐานข้อมูลและตารางคำสำคัญ (Data Schema & Keyword Rules)

6.1 โครงสร้างข้อมูล Transaction

Fieldรายละเอียด
idรหัสรายการธุรกรรมอ้างอิงเฉพาะ
typeประเภทธุรกรรม (income = รายรับ, expense = รายจ่าย)
amountจำนวนเงิน (บาท)
categoryหมวดหมู่ค่าใช้จ่ายหรือรายรับ
transaction_dateวันที่ทำรายการ (YYYY-MM-DD)
descriptionรายละเอียดรายการ
merchantร้านค้า ผู้รับเงิน หรือแหล่งที่มาของรายรับ
payment_methodวิธีการชำระเงิน เช่น โอนเงิน/สแกน QR, พร้อมเพย์, เงินสด, e-Wallet
slip_image_urlข้อมูลรูปภาพสลิป (Base64 / SVG Data URL)
created_atวันและเวลาที่บันทึกข้อมูล

7. ขั้นตอนการทำงานของระบบ (System Workflows)

7.1 การเพิ่มรายการแบบกรอกเอง

  1. ผู้ใช้กดปุ่มหรือเมนู “เพิ่มรายการ (กรอกเอง)”
  2. ผู้ใช้เลือกประเภท รายจ่าย หรือ รายรับ
  3. ผู้ใช้กรอกจำนวนเงิน วันที่ ชื่อร้านค้า หมวดหมู่ และรายละเอียด
  4. ระบบตรวจสอบข้อมูลที่จำเป็นและแนะนำหมวดหมู่อัตโนมัติจากคำสำคัญ
  5. ระบบบันทึกรายการลงฐานข้อมูล LocalStorage
  6. ระบบอัปเดตตัวเลขบน Dashboard และวาดกราฟสรุปผลใหม่ทันที

7.2 การเพิ่มรายการจากสลิป

  1. ผู้ใช้กดเมนู “อัปโหลดสลิปค่าใช้จ่าย”
  2. ผู้ใช้เลือกรูปภาพสลิปจากอุปกรณ์ (หรือกดปุ่มเลือกสลิปตัวอย่าง)
  3. ระบบย่อขนาดภาพด้วย Canvas และแสดงตัวอย่างรูปภาพสลิปบนหน้าจอ
  4. ผู้ใช้กรอกจำนวนเงิน วันที่ ร้านค้า/ผู้รับเงิน และรายละเอียดจากสลิป
  5. ระบบตรวจจับคำสำคัญจากชื่อร้านค้าหรือรายละเอียดแล้วเลือกหมวดหมู่ให้อัตโนมัติ
  6. ผู้ใช้ตรวจสอบความถูกต้องและกดบันทึกข้อมูลพร้อมรูปภาพสลิป
  7. ระบบอัปเดต Dashboard และกราฟสรุปผลทันที

8. สรุปการใช้เครื่องมือ AI ในการพัฒนา (AI Tools Usage Summary)

โปรเจกต์นี้ได้ประยุกต์ใช้เครื่องมือ AI (Antigravity AI Coding Assistant) ช่วยในขั้นตอนต่าง ๆ ดังนี้:

  1. ช่วยออกแบบโครงสร้างโปรเจกต์และ Data Schema: แยกโค้ดออกเป็นโมดูลอย่างชัดเจน ได้แก่ index.html, css/style.css, js/data.js, js/chart-manager.js และ js/app.js
  2. ช่วยเขียนฟังก์ชัน CRUD และการจัดการรูปภาพสลิป: สร้าง DataService สำหรับเพิ่ม อ่าน แก้ไข และลบรายการใน LocalStorage รวมถึงฟังก์ชันบีบอัดรูปสลิปด้วย Canvas
  3. ช่วยสร้าง Logic แนะนำหมวดหมู่แบบ Rule-Based: พัฒนาฟังก์ชัน suggestCategoryByKeyword() เพื่อจับคู่คำสำคัญทั้งภาษาไทยและภาษาอังกฤษเข้ากับหมวดหมู่เริ่มต้น
  4. ช่วยสร้าง Sample Data สำหรับทดสอบระบบ: สร้างข้อมูลตัวอย่างเริ่มต้นพร้อมรูปสลิปจำลองรูปแบบ SVG เพื่อให้ทดสอบระบบได้ทันที
  5. ช่วยตรวจสอบแก้ไขข้อผิดพลาด (Debug) และจัดทำเอกสาร: ตรวจสอบลำดับการทำงานของ JavaScript และจัดทำคู่มือ README.md พร้อมรายงานฉบับสมบูรณ์
